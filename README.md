# متجر العناية بالبشرة والمكياج والعطور

متجر ثابت يعمل مجاناً على **GitHub Pages**، مع **لوحة إدارة** (`admin.html`) تضيف المنتجات والأقسام من صفحة الويب وتحفظها مباشرة في المستودع.

## الميزات
- أقسام قابلة للتخصيص (إضافة / تعديل / حذف / ترتيب) تظهر كقائمة في المتجر.
- منتجات بأنواع متعددة (مثلاً شامبو: للشعر الدهني، للجاف، ضد القشرة) لكل نوع سعره وحالة توفره.
- رفع صور المنتجات من اللوحة (تُصغَّر تلقائياً).
- بحث، سلة تسوق، وإرسال الطلب عبر واتساب.
- تصميم متجاوب مع الجوال وواجهة عربية (RTL).

## خطوات التشغيل

1. أنشئي مستودعاً جديداً على GitHub (مثلاً `my-store`) وارفعي كل محتويات هذا المجلد إليه.
2. من **Settings → Pages**: اختاري Source = *Deploy from a branch*، والفرع `main` والمجلد `/ (root)`.
3. بعد دقيقة يصبح المتجر على: `https://USERNAME.github.io/my-store/`

## إنشاء مفتاح الوصول (مرة واحدة)

1. GitHub → **Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token**.
2. **Repository access**: Only select repositories → اختاري مستودع المتجر فقط.
3. **Permissions → Repository permissions → Contents: Read and write**.
4. انسخي المفتاح (يبدأ بـ `github_pat_`).

## استخدام لوحة الإدارة

1. افتحي `https://USERNAME.github.io/my-store/admin.html`.
2. أدخلي المفتاح (اسم المستخدم والمستودع يُملآن تلقائياً).
3. أضيفي الأقسام والمنتجات، ثم اضغطي **حفظ ونشر**.
4. تظهر التغييرات في المتجر خلال دقيقة تقريباً (وقت إعادة نشر GitHub Pages).

## ملاحظات أمنية
- صفحة `admin.html` ظاهرة للجميع لكنها لا تعمل بدون المفتاح. لا تشاركي المفتاح مع أحد.
- المفتاح يُحفظ في متصفحك فقط. استخدمي "تسجيل الخروج" على أي جهاز مشترك.
- حدّدي المفتاح بمستودع المتجر فقط وبصلاحية Contents فقط.
- الصور المحذوفة من اللوحة تبقى في مجلد `images/` ويمكن حذفها يدوياً من GitHub.

## تغيير الاسم / العملة / واتساب
من تبويب **إعدادات المتجر** في اللوحة. رقم واتساب بصيغة دولية بدون `+` (مثال: `9647701234567`).

## ملفات المشروع
```
index.html      واجهة المتجر
admin.html      لوحة الإدارة
app.js          منطق المتجر
admin.js        منطق اللوحة (GitHub API)
style.css       التصميم
data/store.json بيانات المتجر (أقسام + منتجات + إعدادات)
images/         صور المنتجات (تُنشأ تلقائياً)
```
